# QuestLife 产品决策（第五版）

2026-11-05，由 Kyrie 授权写入。以下决策只有用户本人可以修改。

1. **当前优先级：先让用户本人每天愿意用。** “任何人都能完整使用”放在之后。这一条取代 2026-10-14 的“先完整交付给任何人”。
2. **视觉以第五版为准。** 之后的视觉修改只接受“具体元素 + 具体问题”，不再整页重做。
3. **今日页的核心是“状态 → 行动”。** 状态是 `todayCommand` 的输入，`todayCommand` 仍是今日唯一的主动作权威。
4. **首屏文案 = 一句动作 + 一句短理由。** 不确定性用来源标签表达（规则判断 / 通用依据 / 你的记录 n 次），详细依据点开才看。首屏不堆免责说明。
5. **每增加一项主动记录，都要说明它改变了哪个判断或建议。** 说明不了就不加。
6. **任何日程改动：预览 → 用户确认 → 应用 → 可撤销。** 永不自动改日程。
7. **复杂模型进入决策之前，必须在未来数据上优于“个人基线 + 简单规则”。**
8. **近期交付形态：Web/PWA 是日用主力。** 新版本验收后接管主版本的自定义域名和 GitHub `main`；旧主版本保留为存档。原生 iOS 暂不追求视觉一致，等用户决定是否购买开发者账号。健康和日历数据经 iOS 快捷指令同步。
9. **30 天检验：** 签到天数、状态改正率、是否出现至少一条改变了安排的“对你来说”结论。
