## 组件与复用

| 第五版组件 | 现有基础 | 本轮处理 |
|---|---|---|
| 玻璃卡 / 列表组 | V11Material、QuestCard、V11 sheet | 复用材质、独立外阴影与内裁切，不嵌套大卡 |
| 分段控件 / 主次按钮 | V11SheetControls、V11Pill | 使用同组 token 和 44px 触区 |
| 图标块 / 标签 | QuestIcon、V11RebaselineIcon | 复用既有图标，不再引入图标库 |
| 搜索、加号圆钮 | 既有 IconButton | 圆形、可聚焦、带可访问名称 |
| 底栏 | App.web.tsx 的五栏导航 | 保留路由；换材质与标签为今日/目标/日程/分析/个人 |
| 状态条 / 依据 Sheet | state-layer 纯函数、V11 Sheet | 双量表内联，ACK 后收起；详细解释渐进展开 |
| 主行动卡 | todayCommand + HomeScreen handlers | 不复制动作权威；状态成为输入 |

## 构图与验收

- 今日：日期 → Capture → 状态条 → 主卡 → 后续安排 → 最近执行。390×844 首屏完整看到前四项；不保留旧统计条、重复路径或独立精力卡。
- 目标：紧凑筛选 + 项目方向卡 + 持续方向组。模块/技能到详情；技能库从加号进入。
- 日程：保留 Day/Week/Month/Year 与真实时间轴，删重复建议入口。
- 分析：保留图表工作区；默认状态日历，其他变量可选择；蜡烛中性色，不将涨跌等同好坏。
- 个人：沿用分组，健康/日历明确快捷指令与最近同步状态。
- 桌面内宽受控，不能把手机卡无上限拉伸；所有页面必须有空态、长文、明暗、键盘和滚动检查。
- 截图仅说明浏览器呈现；视觉是否接受由用户判断。
