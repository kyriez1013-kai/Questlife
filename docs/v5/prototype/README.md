## 本轮改动

今日取消旧的判断口号与巨大建议块。顶部直接显示日期、记录入口；计划量与今日实际分开。下一项安排连接到计划详情、目标和实际记录，后续事项按时间排列。当前状态只呈现用户确认后的自评，历史记录显示实际日期。

目标由“展开全部技能树”改为“完成依据 → 两条模块路径 → 下一项计划 → 持续方向 → 技能库”。完成条件未确认时不展示虚构进度。技能库快捷分类、目标搜索与子页入口可操作。

日程收紧顶部间距，保留已认可的时间轴和智能调配；个人移除空标题栏，让身份与数据管理上提。技能、记录、日历和调配等子页统一采用浅色透光按钮，增强边缘高光、层间阴影和信息分区。

分析的脚本、数据和基础样式保持 v4 字节一致；两版在同一浏览器、393 × 852 / 2× 条件下截图完全一致，见 `checks/analysis-pixel.json`。

## 数据与产品边界

目标、日程与记录全部为隔离合成示例。演示日期 2026-11-05：原型设计 09:30–10:15、阅读 14:00–14:30、散步 17:30–18:00，共 105 分钟计划。基线当天实际为零；此前三条实际示例记录合计 95 分钟。记录次数不会换算为目标完成或技能掌握程度。

确认记录后只更新当前页面内存；刷新重置。保存失败保留草稿。调配先审阅差异，示例中只移动阅读，保留 30 分钟时长；过期与撤销冲突会阻止覆盖。没有接入真实智能调度服务。

系统日历、账户同步和通知均未实际连接。日历区分 iPhone / Mac 和读取占用 / 只添加计划，当前原型不请求系统权限或写入事件。HealthKit 仍须在原生 iPhone App 内授权读取；上传不能替代原生读取，健康云同步单独表达。

分析使用截至 2026-06-30 的历史合成产物，与 11 月目标、计划示例分离；89 个日观察、14 根周 OHLC、缺失日不补零，EWMA 为历史平滑而非预测。
