# QuestLife v5 · 设计与行为记录

## 最新授权优先

用户撤回 Today 必须延用旧布局的要求。本轮 Today 和 Goals 可以重新设计；Analysis 必须保持原样。所有改动只在独立交付目录。

## 今日

日期 / 历史入口 → 记录输入 → 计划与实际汇总 → 下一项明确安排 → 后续安排 → 当前精力 → 最近执行。没有“保守启动”或推测状态的主标题，也没有用未采集信号生成建议。

接下来一项来自固定演示时间 09:20 下的 09:30 计划，不是模型推断。点击记录不会自动标记计划完成，实际记录只在确认保存后加入。首次使用与读取错误单独表达。

## 目标

顶部用方向数量和有效入口取代空标题栏。主项目先展示两项待确认结果条件，再展开到两条模块路径。模块继续通向技能与执行。没有虚构进度条或掌握分数。

持续方向单列；技能库保留复用与分类。目标搜索拥有独立输入绑定，按目标和关联技能过滤。增加的第 31 个导出子页为查找方向。

## 材质与排版

冷白背景、低饱和蓝灰、薄内高光、边缘折射感、低位阴影；大字仅限具体对象名称或少量数字，不再设置重复导航名称的大页首。子页主要操作使用带边缘高光的浅色玻璃面和深色文字，不使用实心全蓝背景。非分析页面的新增样式均有范围限制。

## 分析保护

v4 的 app.js、analysis-data.js、style.css、flows.js、flows.css 没有改变。refine.js / refine.css 在其后加载，所有视觉新增限定于目标页面或非分析子页。对 v4 与 v5 的分析页分别以相同浏览器和单屏画板渲染，PNG 字节完全相同。

## 实现范围

36 个静态截图入口；点击后有更深的动态交互状态，例如记录审阅、失败、调配完成、撤销冲突与编辑技能。截图数量不等于所有状态数量。系统服务连接、真实权限、持久化和模型能力未实现。
