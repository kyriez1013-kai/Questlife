## 本轮发现并修正

- RN Web 根容器背景覆盖第五版色场，改为仅 V5 下透明，旧/原生不改变。
- 主行动错误复用了“开始时间”翻译；调节动作显示原任务 45 分钟，已改为对应 10/20/5 分钟。
- 底栏内置 flex 压缩文字至 9px，高度不足导致中文裁切，已限定 V5 文字不收缩，加入浏览器回归检查。
- SQL 的 NULL 三值逻辑可能放过缺少 inbox 标记的 pending Capture，修正 coalesce false 并验证旧边界不放宽。
- Finish 快捷表单与校准只在 V5 Web 生效；RN 不访问不存在的 window.location，`v5_ui=0` 保留既有表单。
- 云端 API 非 strict 编译复现 AuthResult 收窄错误，显式布尔判别后独立 API 类型检查通过；该检查纳入部署门禁。
- 第一版候选 8347842 首次在线加载后立即断网刷新得到空正文，缓存只有四个 shell 文件；Worker 增加启动 JS/CSS 原子预缓存，之后必须重新验证固定站点离线重开。
