## 4. 修改清单

### 4.1 所有页面
- **部署后的网站在不带任何 URL 参数时，五个底栏页面全部是第五版界面。** 检查路由和 UI 开关，确认日程和分析不再落到旧组件。旧界面只能通过显式参数回看。
- **底栏不再叠字：** 页面底部留出"底栏高度 + 安全区"的空白；底栏背景加强模糊和不透明度。
- **界面上不出现任何英文测试字符串。** 中英混用的单位统一成中文（"35 分钟"，不是"0h 35min"）。
- 加载状态最多显示 3 秒，之后显示空状态或明确的错误和重试，不允许无限转圈。

### 4.2 今日
- **状态条**改成与第五版"此刻精力"行同样式的玻璃行，放在记录框下方：左侧"此刻状态"，右侧"未记录 · 记一下"；签到后显示"过载 · 挂着的事较多 · 09:20"。不要用蓝色文字链接。
- **主卡在正常日程上不显示"规则判断"标签**，只在"建议先做"这类系统建议上显示来源标签。
- 删除主卡里重复的"根据今日计划 09:30–10:15"。
- "更多"改成与其他次要操作一致的样式（如右上角"…"图标）。
- 技能没有"需要的状态"时，什么都不显示（不显示"未标注"）。
- 主卡高度与第五版一致，不能占半屏。

### 4.3 目标
- 卡片高度贴合内容，去掉底部空白和孤立的"…"（移到右上角）。
- 页头"本周投入"用中文单位；没有数据时不显示。

### 4.4 日程（按第五版重做，替换旧界面）
- 结构：月份标题 + "＋"圆钮 → 日 / 周 / 月 / 年分段 → "调整建议""日历同步"两个玻璃胶囊 → 周日期条 → 当天标题行 → 带"现在"红线的时间轴卡片 → 待安排事项。
- 删除旧界面的"可视化你的时间和精力分配"、黑色"添加日程"大按钮、"现在 / 下一步"列表。功能入口保留在新结构里。

### 4.5 分析（按第五版重做，替换旧界面）
- 结构：变量选择胶囊 + 日期范围胶囊 → 趋势 / 分布 / 对比 / 相关分段 → 图表卡片 → 四格数字 → 当前分析卡 → 底部五个工具入口。
- 默认变量为"状态"，趋势视图显示状态日历。
- 删除旧的"个人观察"页面结构（白色方块按钮、"连接健康来源"大按钮）。数据来源入口移到"个人"页。

### 4.6 空状态（第五版没有画，按这里实现；原型源文件里有的以原型为准）
