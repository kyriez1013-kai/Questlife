## 2. 今日：重新设计（不要大卡片）

**用户最不想看到的是一张占大面积的卡片**，比如"今天，从一件事开始"那种大标题大卡。重新设计成**紧凑的分组列表**，视觉语言参照已还原的"个人"页（玻璃分组列表行）和"日程"页。

### 设计原则
- 首屏不允许出现高度超过 96px 的单个卡片（记录框除外）。
- 全页最大的字是"下一步"那一行的动作名称，17–18px 半粗体。不使用 24px 以上的字。
- 每一行都是"图标 + 标题 + 一行副标题 + 右侧操作"的列表行，行高约 56–64px。
- 界面上不出现"签到""打卡"这类词。用户看不懂"签到"是什么。统一叫"记录状态"。

### 页面结构（从上到下）
1. **日期头**：沿用第五版。
2. **记录框**："随手记一句…"，沿用。
3. **"现在"分组**（一个玻璃分组，两行）：
   - **此刻状态**：未记录时副标题写"点两下：精力和紧绷"，点击后在行内展开两排 5 档，选完自动保存并收起；已记录时显示"过载 · 挂着的事较多 · 09:20"。超过 3 小时变弱显示"09:20 · 过载 · 现在呢？"。点右侧箭头看依据。
   - **下一步**：显示 todayCommand 给出的唯一动作。标题是动作，比如"原型设计 · 09:30–10:15"；副标题是一句短理由；右侧一个小胶囊按钮"开始"。
     - 状态与任务不匹配时：标题前加小标签"建议先做"，标题如"清空脑子 · 10 分钟"；分组里多出一行"原型设计顺延到 10:30"，右侧小胶囊"调整"，走现有的预览 → 确认 → 撤销。
     - 进行中：标题显示已进行时间，右侧胶囊"完成"，完成后沿用现有的分钟、难度、备注记录。
     - 回访到期：多出一行"刚才清空脑子后，现在精力？"，右侧五档一键。
     - 完全没有数据和日程：标题"记一句现在在做什么"，右侧胶囊"记一句"（聚焦记录框）。和其他情况同样大小，不放大。
4. **"今天"分组**：今天的日程，每行"时间 · 名称 · 时长 · 需要的状态小标签"。没有日程时只有一行"今天没有安排"，右侧小胶囊"添加"。分组标题右侧"完整日程"。
5. **"最近"分组**：最近 3 条执行记录；没有记录时整组隐藏。

### 必须保留的行为
记录状态、todayCommand 作为唯一主动作、调整的预览/确认/撤销、执行完成的难度记录、回访、依据 Sheet，这些逻辑都不改，只换展示。

## 4. 分析：直接显示图表

**用户要的是第五版样板图那样，打开就能看到图表（K 线或折线），不要文字提示。** 删除"当前范围没有合格观察"这类整块提示文字。

1. **整页结构按第五版原型的"分析"画板实现**：变量选择胶囊、时间范围胶囊、趋势/分布/对比/相关分段、图表卡片（K 线 / 折线切换、缩放、全屏、底部范围滑块、7天/30天/90天/1年/全部）、四格数字、当前分析卡、五个工具入口。
2. **只要有真实数据，就画出来**，哪怕只有 1–2 个点。"合格观察"的门槛只影响"当前分析"卡里的结论文字，比如"数据还少（3 天），先看走势，暂不下结论"，一行即可，不影响图表显示。
3. **某个变量完全没有数据时**：图表照常显示，用一组示例数据，卡片标题旁放一个明显的"示例"小标签，下面一个小按钮"开始记录"。四格数字和当前分析卡同样标"示例"。**示例数据只在这个变量完全没有真实数据时出现，绝不和真实数据混在一起。**
4. **默认变量**：选真实数据最多的那个变量（比如健康同步后的步数或睡眠）；都没有时默认"精力"。
5. **去掉状态日历。** 用户看不懂它。"状态"相关的变量改成折线图：精力、紧绷各一条线（1–5），可切换；图表下方可以加一条按天着色的细状态条，作为辅助。
6. 蜡烛图保持中性单色，不用红绿。
