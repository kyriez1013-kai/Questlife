## 5. QA 英文记录问题

历史证据位置：[V1_COMPLETION_LEDGER.md](../../release/V1_COMPLETION_LEDGER.md) 第1697–1702行：此前正常 Chrome 候选界面验收创建过一个**本地** `QA Candidate Backup Roundtrip` 目标；该轮没有登录或云上传，清理尚未完成。这能说明名字的已知来源，**不能证明当前用户账号是否持有相同 ID 的记录，也不能证明远端是否有副本**。

本轮确认：全新浏览器五页不出现这个 QA 字符串；新 V5 页面代码没有默认灌入该记录。未检查 Owner 私人记录，未删除任何49条隔离测试数据，未进行猜测式按名称过滤、批量删除或跨身份复制。

未解决：缺少当前残留记录的稳定 ID、原始隔离身份与 provenance 证据，无法安全地把用户现有那一条移走。现有匿名浏览器残留不会因为换 UI 自动消失，返回用户仍有可能看到它。该项继续阻塞硬验收；本报告不把“新浏览器没有”写成“用户账号已清洁”。
