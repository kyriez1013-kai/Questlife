# QuestLife Stage 3.11 - Commercial Terminal Audit

Baseline reviewed: Stage 3.10 local screenshots and isolated terminal code.

## Keep

- One primary personal time-series canvas.
- Personal -> Goal -> Skill analytical scope.
- Materialized Quant artifacts and exact source lineage.
- Personal reference center and range.
- Event rail, range selection, comparison, Signal, Evidence, and Analyst.
- Lightweight Charts as an unbranded low-level renderer.

## Refine

- Numeric hierarchy: current reading first, reference second, metadata third.
- Chart depth, grid restraint, axis labels, event markers, and baseline band.
- Toolbar language around QuestLife actions rather than renderer controls.
- Mobile density and desktop center/right-column balance.
- Analyst as a visible contextual inspector rather than an empty destination.

## Replace

- Smooth periodic review data with seeded, realistic longitudinal fixtures.
- Empty Goal/Skill navigation for passive-only users with an instrument rail.
- Generic candle semantics with explicit observational bucket semantics.
- Sparse Signal detail with a traceable compact evidence inspector.
- Day-1 empty Analyst copy with a current/reference/coverage brief.

## Remove

- Redundant `QUESTLIFE QUANT` page branding.
- Chart-adjacent TradingView copyright/logo block, after compliant relocation.
- Disabled or unsupported chart representations.
- Permanently enlarged secondary horizon metrics.
- Product-facing artifact, fixture, engine-version, and evidence-code labels.

## Acceptance focus

Day 1 must explain the latest reading, personal reference, recent deviation,
coverage, and one useful interpretation in roughly one mobile viewport. Day 90
must visibly add Signal, related context, evidence, Analyst detail, and the
historical-to-active transition. The difference must be structural, not merely
different numbers.
